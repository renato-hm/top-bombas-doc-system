# Top Bombas — Sistema de Gestão de Documentos e Assinatura Digital

## 📌 Objetivo

Este repositório contém o planejamento e desenvolvimento inicial de um sistema para digitalizar o processo de arquivamento de notas fiscais e confirmação de entrega (canhoto) da Top Bombas, empresa de venda e manutenção de bombas.

Atualmente, esse processo é feito de forma manual, com alto volume de notas fiscais arquivadas fisicamente. O objetivo é criar uma ferramenta que facilite a consulta, o registro e a validação dessas entregas.

## ✨ Funcionalidades planejadas

- 🔍 Consulta de notas fiscais por nome da empresa
- ✍️ Assinatura digital do cliente no momento da entrega
- 📍 Registro automático de localização (GPS) e horário da assinatura
- 🔄 Atualização automática do status da entrega

## 🛠️ Tecnologias (previstas)

- HTML, CSS, JavaScript (fase inicial)
- A definir: backend e banco de dados

## 📂 Estrutura do projeto
